# MCP 首版实现与验证记录

日期：2026-10-04。使用说明见 [扩展 README](../extensions/huobao-mcp/README.md)。

## 交付范围

- 独立 TypeScript MCP 扩展，17 个制作工具，标准 Streamable HTTP 和 stdio 桥接。
- 网页设置中的 MCP 面板：免配对连接、真实持久化开关、连接信息复制、运行历史及暂停运行恢复。
- 统一原 HTTP 适配、敏感字段过滤、逐项写入回执、请求去重、内容指纹、制作计划与运行检查点。
- 关闭时的派发屏障；重启后保留开关、暂停旧运行、继续观察已提交任务；不明确提交可绑定经核对的原任务 ID。
- 审阅记录、局部重做计划、匹配目标的历史产物选择。
- 独立 Dockerfile、可选 compose 与 nginx 配置示例。未修改原后端或原数据库结构。

## 已复查的实现边界

- 所有业务访问只经过既有 HTTP，不导入原服务端模块、不读写其 SQLite。
- 网页控制面不设管理会话，保留 Host/Origin 检查；MCP 工具继续要求 Bearer 凭据；敏感配置、原始任务参数及 Provider 错误正文不进入工具结果。
- 生成自动回写、批量非原子、并发指纹非 CAS、不能取消上游任务等限制在工具和 README 中明确。
- 请求的实际执行与扩展记录之间没有跨系统事务，因此不宣称 exactly-once。
- 只有当前输入已就绪的计划可执行；跨阶段依赖需要前一阶段完成后重新规划，不提供任意自动依赖图。
- 一份 MCP 凭据具有绑定后端全部项目的访问范围；当前是个人/受控环境扩展，不是多租户平台。
