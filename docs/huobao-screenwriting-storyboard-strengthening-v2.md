# Huobao 剧本与分镜能力加强方案

2026-10-05。依据：当前生效的 Agent / Skill 配置、项目 4《创可贴》的剧本与 5 条分镜，以及文中链接的一手资料。本次完成研究与文字诊断，未重新生成剧本、修改运行配置或评审现有视频画面。

**建议优先加强三项能力：写出人物变化的过程；设计相邻段落的连接；让分镜真正完成一次镜头设计。** 继续使用现有“AI 改写 → 分镜拆分 → 视频提示词”入口和同一个服务端。先调整可配置提示词、示例及两端共用检查，不新增制作流程，也不改原服务端源码。

**当前问题在哪里**

| 已核实的情况 | 对质量的影响 | 应改什么 |
| --- | --- | --- |
| 《创可贴》剧本已经写入“从背后看”“画面跟着”“切到镜子”等指令，5 段剧本随后对应 5 条分镜；S02、S03、S05 的描述基本照搬 | 摄影选择过早固定；分镜阶段容易只给原文加景别标签 | 剧本保留事件、可见动作和揭晓约束；分镜重新决定构图、取景、调度和切点。不按段落数量机械拆镜 |

以上是文本和实现层面的发现。没有据此断言已生成视频一定出现了这些问题。

**吸收哪些专业方法**

| 方法 | 用通俗的话解释 | 在 Huobao 中怎么用 |
| --- | --- | --- |
| 故事节拍与因果 | 重要的是人物作了什么决定、局面怎样改变 | 改写时检查每个关键变化的起因、行动、结果；时间跳跃和并行事件也可以成立，不硬凑每段直接因果。依据：[Pixar / Khan《Story spine》](https://www.khanacademy.org/partner-content/hass-storytelling/storytelling-pixar-in-a-box/ah-piab-story-structure/v/video1a-fine) |
| 反应中的思考过程 | 先注意到，再理解，再做出反应；脸和身体可以有先后 | 把“很惊讶”改成能演的变化，避免眼睛、嘴、手脚同时夸张运动。依据：[Dana Boadway-Masson《Facial Animation 101》](https://www.animationmentor.com/blog/facial-animation-101/) |
| 场与场的视听连接 | 前一段留下的动作、声音、物件或疑问，由后一段接住 | 为关键转场写清“从什么切走、下一段用什么接住”，不默认加淡入淡出。依据：[David Bordwell《The Hook》](https://www.davidbordwell.net/essays/hook.php) |
| 分镜中的调度和构图 | 决定观众站在哪里看、先看谁、何时知道重要信息 | 分镜必须新增位置、取景范围、注意力安排和切点；保留剧情不等于复制句子。依据：[Disney Story](https://disneyanimation.com/process/story/)、[Pixar / Khan 分镜练习](https://www.khanacademy.org/computing/pixar/storytelling/film-grammar/a/exercise-5-film) |
| 动态分镜预演 | 把粗图按时间播放，才能知道笑点、停顿和转场是否读得懂 | 文字过关后，用粗图和临时声音验证节奏，再投入正式视频制作。依据：[Pixar / Khan Storyreels](https://www.khanacademy.org/humanities/hass-storytelling/storytelling-pixar-in-a-box/ah-piab-pitching-and-feedback/v/pitching4) |

下面的检查格式和示例是针对本项目的综合建议，不是上述机构的统一规范。

**AI 改写：从复述情节，改成可表演的剧本**

在现有 `script_rewriter` 的一次调用内完成：核对原文和改编边界，安排关键节拍，写剧本，再按检查项修正。用户仍然点击原来的“AI 改写”。

关键段落需要回答四件事：人物此刻想做什么；什么使他改变注意或行动；变化怎样表现出来；这一段结束后发生了什么改变。普通走路、交代地点不必机械写满四项。

人物反应可以用“刺激 → 察觉 → 理解 → 反应/选择”检查，但不强制拆成四个镜头。动作要符合人物：顽皮的弟弟被发现后先装镇定，温和的哥哥看清证据后才露出无奈的笑；不能两个人都套用同一套瞪眼、后退、张嘴。

转场分别处理：

- 同一行动持续：交代尚未完成的动作和下一段接上的阶段，避免重复起步、重复发现。
- 转向另一个对象：让目光、声音或动作先触发注意转移。
- 时间或地点变化：保留观众能识别的线索。夜晚切到清晨可以直接切，只要新时空看得懂。
- 省略过程：留下足够前提，让结果可推断。《创可贴》应继续省略贴脸过程，保留镜中第一次揭晓。

剧本正文输出场景、可见行动、必要声音与逐字台词。诸如“镜中才首次看清脸上的创可贴”属于叙事约束，应保留；具体用什么景别和机位交给分镜。不要把制作说明、分析表和自检报告混进正文，也不要把所有短片硬套完整三幕。

建议在改写 Skill 中加入这样的短示例：

> 不足：Otah 看到创可贴，很惊讶，然后转头看 Chaotah。
>
> 可表演：Otah 在镜前抬眼。半合的眼睛慢慢聚焦；他眨了一下，额头上的彩色贴片仍在那里。目光停住，脑袋才缩回一点。身后漏出一声压低的笑。他先把眼睛偏向声源，随后转头。

示例演示反应的原因与先后，不规定每个角色都必须眨眼、缩头。成稿仍需服从全片时长，不能靠添加一串同义动作提高“细节量”。

**分镜拆分：从人物经历，转成观众看到的东西**

`storyboard_breaker` 应先确定信息顺序：这一刻角色知道什么，观众知道什么；哪些信息必须看到，哪些暂时不能看到。然后选择镜头。一个剧本段落可以拆成多镜，也可以与相邻段落合并成一个连续镜头。

每条分镜应新增这些具体决定：

| 决定 | 示例 | 放到现有哪里 |
| --- | --- | --- |
| 观众本镜要读到什么 | 首次看清脸上的创可贴，并读到 Otah 从困倦到察觉 | `description` 中简洁交代；不另建业务对象 |
| 画面从哪里开始 | 只在镜内看见 Otah 的脸，眼睛半合，尚未惊讶 | `description` 开头、`image_prompt` |
| 谁在何处，画面能看见什么 | 保留镜框证明是倒影，构图足以读清眼眉，Chaotah 暂不入画 | `description`，配合 `shot_type`、`angle` |
| 动作如何展开 | 聚焦、短暂停住、眼睛睁大，身体随后小幅缩回 | `description` 的可见表演，转写进 `video_prompt` |
| 摄影机为何这样拍 | 用稳定近景承接揭晓，表演过程中不转移注意力 | `movement` 及必要的取景约束 |
| 怎样结束并接到下一镜 | 表情变化读清后结束；下一镜从已惊讶状态接上，再听见笑声 | `result` 和相邻镜头开头 |
| 视听表现 | 晨光方向稳定、柔和水彩；笑声出现时要能触发转头 | `atmosphere`、`sound_effect`，需要生成执行的内容写入 `video_prompt` |

“叙事风格转成镜头风格”也要具体：儿童喜剧可以让准备动作稍有迟疑、揭晓清楚、反应有停顿；悬疑可以限制可见范围、延迟证据、利用画外空间；人物戏可以用距离、视线和沉默表现关系变化。以上是创作选项，要按剧情选择。“水彩”“3D”解决画面外观，不能替代这些叙事选择。

**用当前 7 秒 S04 举一个完整转译例子**

保留它的故事内容和总时长，先尝试一个足够清楚的连续镜头，并不因为要“更专业”就增加切镜。以下仅为方案示例，未写回项目。

| 层次 | 应交付的内容 |
| --- | --- |
| 剧本 | Otah 看清镜中脸上的彩色贴片，从困倦变为惊讶；具体表演见前述动作写法 |
| 分镜描述 | 承接前镜已在镜前站定的状态。稳定近景，保留镜框边缘，画面内只有倒影中的一张脸；彩色贴片在此首次清晰可见。Otah 半合眼抬起视线，聚焦后眨一次，目光短暂停住；随后眼睛睁大、嘴微张，脑袋才小幅缩回。构图持续保住整张脸，结尾让反应读清。Chaotah 不入画 |
| 起始画面 | 镜框内是带彩色贴片的 Otah，眼睛半合、嘴放松、脑袋未后缩；不写眨眼、发现和惊讶过程 |
| 7 秒表演预算 | 前约 2 秒：抬眼、聚焦；中约 3 秒：辨认、表情改变、身体跟随；后约 2 秒：保持反应供观众读清。属于试演预算，不声称生成模型能精确逐秒执行 |
| 结束状态 | Otah 已看清异常，仍看着镜子，惊讶尚未转为微笑。下一镜从这个状态接上，由笑声触发寻找 |
| 视频提示词 | 固定近景，透过保留边缘的镜框看 Otah 的倒影，画面只出现这一张脸。额头和两颊的彩色创可贴从开始就清晰可见，避开眼睛、鼻孔和嘴。Otah 起初眼睛半合、嘴放松，抬眼聚焦，眨一次后短暂停住；眼睛随后睁大、嘴微张，脑袋稍后小幅缩回。结尾维持这个反应，不再重复一次发现，也不转头或微笑。机位保持不动，脸不出画，贴片位置不变。无台词、无旁白 |

这里新增的是取景范围、观众何时获得信息、表演先后和与后镜衔接；并没有靠增加焦距、材质参数来冒充镜头设计。镜面生成依然需要样片验证，文字约束不能保证反射正确。

S05 可以再根据预演决定：一个足够近的双人镜头能否同时读清余下创可贴、弟弟憋笑和哥哥的反应；若读不清，再拆出证据或反应镜头。不要预先规定“一句话一个镜头”。

**提示词具体怎么改**

采用“短规则 + 完整对照示例 + 保存前检查”的组合，避免主提示词和 Skill 重复堆积同样的口号。

| 配置 | 主提示词负责 | Skill 负责 |
| --- | --- | --- |
| `script_rewriter` / `script-rewriter` | 原文与约束优先级、正确读取与保存、正文范围 | 因果节拍、人物反应、转场线索；放入无对白喜剧、对白关系戏、信息延迟型悬疑三个短示例 |
| `storyboard_breaker` / `storyboard-breaker` | 必须读已确认剧本和资产；允许重新组织镜头；保持事实、台词和揭晓约束 | 同一段剧本如何形成不同有效取景方案；选择适合时长和模型的一种；示范起始、过程、结尾及相邻承接 |
| `prompt_generator` / `prompt-generator/video-prompt` | 保持已确认的分镜内容，遵守所选更新范围 | 把取景、表演、时序、音频要求写入实际生成提示词；消除首尾状态冲突，不擅自增加剧情 |

分镜 Skill 的核心要求可写成：

```text
不要按剧本编号或自然段数量决定镜头数量。
保留既定事件、人物关系、台词和信息揭晓时机，重新设计观众的观看位置。
关键分镜写清：起始画面、可见表演、构图与调度、结束状态。
发生切镜时，检查前镜结束到后镜开始之间，视线、动作或时空线索如何连接。
如果原剧本已有充分有效的镜头设计，可以保留；不能为避免文字相似而无意义改写。
image_prompt 只描述起始的一个静止时刻，不能把最终反应提前画出来。
video_prompt 必须包含执行本镜所必需的取景、动作、顺序与声音要求。
保存前检查事实与揭晓、人物反应、镜头衔接、首尾状态、时长；发现具体矛盾先修正。
```

三条执行边界需要写明：

- 一条 Huobao 分镜记录目前也是一段视频生成任务，不能把“剪辑镜头”和“模型生成段落”直接等同。先按现有模型适配器的时长范围设计可执行方案；段内多镜切换需要验证，不能承诺精确切点。
- 跨片段 J/L cut 需要音轨错位与剪辑支持。第一轮优先做可见动作、视线和时空线索连接；同段内画外笑声可以作为表演触发，不把它冒充已实现的跨片段混音能力。
- 当前“仅生成视频提示词”请求只允许改 `video_prompt`。如果问题在剧本、分镜或起始画面，要明确返回对应修改建议；不能越权只修一个字段，留下其他字段继续矛盾。

**如何判断改动有效**

先做文字对比，不用付费视频来检验明显的剧本错误。固定同一输入、同一模型配置和时长约束，对三个题材分别保留旧版与新版各至少两次输出，避免只挑一次成功结果。比较时隐藏版本名称。

| 检查 | 合格证据 |
| --- | --- |
| 人物反应 | 关键变化能找到可见/可听的触发，前后情绪和行动相容；没有为丰富细节追加无关动作 |
| 转场 | 看相邻两段就能理解持续行动或时空变化；没有重复发现、突然换位、无由转头 |
| 镜头转译 | 分镜明确新增了取景、位置、注意力或切点决定；原剧本已有有效设计时允许保留 |
| 信息揭晓 | 指定揭晓前，文字、构图和起始画面都没有提前泄露；无对白片没有新增解释性旁白 |
| 状态一致 | 起始画面没有提前包含最终表情；上一镜的已完成动作不会在下一镜重做 |
| 时长可执行 | 总时长符合要求；单段范围符合当前适配器；关键动作有表演空间。文字预算通过不等于实际视频通过 |

问题报告必须指出具体段落、冲突原文和建议，不能只给一个“专业度 90 分”。文字相似度最多辅助定位复制，不能作为硬性不合格标准，尤其不能惩罚准确保留台词和人物名字。

文字对比通过后，再用粗图做一次动态预演，观察不看说明的人能否理解起意、揭晓和反应。本轮先把它作为制作验收办法；不要求先开发一个新的预演平台。正式视频再验证表演执行、镜面、声音与相邻片段是否真的衔接。

建议实施顺序：先完成三组配置及正反例，再补共用输入和检查展示，随后做隔离文字对比。优先解决“会写动作，但不会安排观众怎么看”的问题，成片表现再通过预演和样片确认。
