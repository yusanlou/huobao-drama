# 当前网页与 MCP 功能差异核对

日期：2026-10-04。对照基线：[MCP v1 设计提案](./mcp-service-design-v1.md)。本文是对 v1 的历史核对，不修改实现。

后续方向已调整为 [面向模型、复用原服务端的独立扩展 v3](./mcp-service-design.md)。本表保留为业务能力调查，网页一对一覆盖不再作为 MCP 的设计目标或验收标准。

## 核对口径

通过当前已打开的 Chrome 火宝页面检查了项目首页、新建项目、项目详情、新建剧集、项目素材库、资产详情、原文/AI 改写、资产制作、视频制作、批量生成确认、任务抽屉、拼接导出，以及设置页全部六个分类。

核对地址为 `http://localhost:3013/`、`/drama/1`、`/drama/1/episode/1`、`/settings`。检查了项目“奇闻逸事”的现有页面。未保存配置或内容，未发起生成/合成/测试模型，未删除数据。最后回到原项目素材库。

“页面可用”在本文表示有对应操作入口及代码支持，不表示本次执行验证通过。无现成数据的条件分支通过源码补查并标注；桌面专属能力未在当前服务器模式网页中实测。

| 对比对象 | 当前状态 |
| --- | --- |
| 当前网页 | 核心制作、配置与管理页面已存在 |
| 当前仓库 MCP 实现 | 未发现 MCP 入口、工具注册或 MCP 依赖；`backend/src` 无相关实现 |
| 当前会话可调用的火宝 MCP | 未发现 |
| 上轮 MCP 方案 | 只有设计文档，所有 `hb_*` 工具均未实现 |

**因此，以下所有网页功能在“当前 MCP”中均未实现。表格的“方案覆盖”仅衡量设计覆盖程度，不表示工具已可调用。**

标记：已规划＝设计明确包含；待细化＝有对应工具但字段、范围或行为不够明确；遗漏＝没有明确对应动作；行为不同＝有意改变网页现有行为；界面保留＝不需要制作 MCP 对等实现。P1/P2/P3/P4 沿用原提案。

| F13 | 跳过改写：把原始内容作为剧本并进入制作 | 待细化 P1/P3：保存剧本、跳过改写步骤 | 方案提到跳过，但需定义复制原文的命令语义；仅“省略 AI 调用”不等价 |
| F14 | 顶栏临时选择文本/图片/视频模型，选择保存在浏览器 | 待细化 P1：生成工具的 model/config_id 覆盖 | MCP 单次覆盖不会修改浏览器本地选择；返回生效配置，不能承诺下拉框跟着同步 |

## G. 反向差异：方案新增，不能计作当前网页已有能力

| 能力 | 当前网页/后端现状 | MCP 方案 |
| --- | --- | --- |
| 正式工作流计划、暂停、续跑 | 人工逐步操作，未发现持久化整集工作流 | P3 新增 |
| 版本化验收、退回意见、检查点 | 手动完成标记不等价于验收系统 | P3 新增 |
| 所有长任务统一 job_id 与事件 | 媒体有记录，Agent/提取/提示词状态不统一 | P1/P2 新增 |
| 后端重启恢复在途任务 | sys_task 启动时标失败，部分任务仅内存状态 | P2 新增 |
| 请求幂等、未知提交防止重复收费 | 未发现通用机制 | P1/P2 新增 |
| 草稿原子提交、编辑冲突检查 | 当前有直接覆盖/分批写入 | P1 新增 |
| 图片候选历史、统一 artifact、上游变化失效追踪 | 视频有局部历史，其他尚不统一 | P1/P3 新增 |
| 通用取消任务 | 删除记录不取消 Provider 任务 | P2 新增，受 Provider 能力限制 |
| 手工分镜增删/重排、首尾帧/分镜图生成 | 后端有部分基础；本次当前视频工作台未见对等入口 | 属于方案扩展/底层能力，不应算作“网页缺失覆盖” |
| 参考视频/音频上传 | 后端有上传路由，当前工作台绑定区仅看到角色/场景/道具图片 | 不列为当前可见网页能力；若扩展需另验收 |

## 最优先修订的设计项

| 优先级 | 修订项 | 原因 |
| --- | --- | --- |
| 高 | 明确手动项目/剧集状态与工作流/审核状态的区别 | 保留网页“标记完成”的原有含义 |
| 高 | 明确项目/剧集资产范围、完整字段及 prompt 失效规则 | 避免 MCP 改了数据，刷新后与网页本地状态不同 |
| 高 | 补齐批量选取、补缺/强制、失败重试及提交前摘要 | 这些是现有制作效率的重要能力，不能只写“支持 batch” |
| 高 | 定义生效模型与网页本地选择的关系 | 同数据不等于浏览器偏好也同步；费用与产出依赖实际配置 |
| 中 | 将只读风格/厂商模板发现前移到 P1 | Codex 创建项目和选择能力需要枚举支持 |
| 中 | 补厂商模板、火宝快捷配置、默认模型动作 | 当前均含前端组合逻辑，简单配置 CRUD 不完全等价 |
| 中 | 补 Prompt reset、语言与 fallback 参数 | 避免覆盖错误文件/语言 |
| 中 | 保留部分拼接，同时区分完整成片 | 工作流完整性约束不能取消网页现有部分导出能力 |
