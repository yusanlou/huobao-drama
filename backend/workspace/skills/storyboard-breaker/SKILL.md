# 分镜导演规范

从完整事件拆解，不按原文字数或固定时长模板切块。阅读当前集的剧本、description 制作要求和已有资产。原剧本台词逐字继承，若无法在段落时长内说完，先调整分段，明确需改剧本的地方，不能擅自漏词或加速成不可识别人声。

每个段落先确定观众应看到的新信息。用建立空间、动作证据、必要反应及结果来组织镜头，不强制每段都有推拉摇移。景别解决信息量，机位明确轴线与视线；运动跟随主体或揭示信息，无理由就固定机位。切点对齐动作完成、注意力转移或信息揭示。

description 描述起始位置、动作方向、速度变化、碰撞/接触与结束状态；多人或多物体时写清作用关系。atmosphere 写主光方向、遮挡、软硬、亮暗层次、色温倾向和可见纹理。材质用实际画面表现：漫反射、湿润高光、布料受力、尘粒受光，而非模型不能精确兑现的物理常数。result 留下给下一镜的接点。

连续性核对人物位置、朝向、持物手、服装/道具状态、灯位及动作阶段。普通物理规律与设定中的异常区分：先交代稳定基准，再说明异常从哪里开始、如何变化、停在哪里。不要把“怪诞”只写成气氛形容词。

duration 是本段秒数；动作和台词可以重叠，但不同说话者的台词不能无理由重叠。有目标时总和核对，无目标时明确估计；不以镜头描述字数计算旁白时长。不靠截断台词满足时限。

素材只绑定本集实际资产，纯旁白人物不强制入画。image_prompt 写单帧，video_prompt 写变化、摄影、逐字声音与必要限制；声音意图字段不等于声音生成任务。整集重建使用原保存工具，单镜修改限定 ID 与字段。

语音预算自查：中文旁白先以每秒约 3–4 个汉字、英语每秒约 2–3 个词作为保守规划估计，另给呼吸、动作与末句留余量，不视为实测语速。台词不够时间时调整本镜预算及相邻段落；不能为了总时长凑数压缩到念不完，也不能擅改已经确认的原台词。最终提示词写全逐字台词并标明完整结束，拒绝以“极快语速”解决。

## 将故事变成观看顺序

先决定本段让观众知道什么、暂时不知道什么，再选择取景与调度。剧本一段可拆成多镜，多段也可合并；已经有效的设计允许保留，不以改写字数证明转译。每条 description 必须给出能执行的画面：起始构图/位置、可见动作先后、结束状态。摄影字段配合画面任务；切镜发生时要有动作、注意转移、揭晓或时空改变的依据。普通固定镜头同样有效。

image_prompt 是单一静止起点，不能写走近、站定、惊讶的全过程，不能已呈现最终反应。result 是终点；video_prompt 连接二者并继承必要取景条件。先核对相邻段的方向、持物、动作阶段和情绪进度，尤其不能每镜重演一次初次发现。图片 URL 不等于你已看懂图片；未实际看图时依据明确的资产文本，不杜撰布局。

## 三个转译示例（不复制示例的剧情）

喜剧，剧本：“困倦的哥哥在镜中看清脸上的贴片，惊讶。”
不足：原句加“近景、固定机位”。
可执行描述：保留镜框边缘，只在倒影中看见一张脸；贴片在此首次清晰可见。半合的眼睛抬起、聚焦，眨眼后目光停住；眼睛再睁大，脑袋稍后缩回。画面始终保住整张脸，弟弟不入画，反应读清后结束。
image_prompt：镜框中的贴片脸，眼睛半合、嘴放松、脑袋未缩回。
result：已经惊讶，仍看镜子，尚未转头或微笑。下一镜从此状态接上，再以笑声触发转头。

人物戏，剧本：“守门人认出钥匙上的红线，放来客进门。”
可执行描述：侧面中近景同时容纳拦门的手、钥匙和守门人的眼睛，红线不能小到不可辨认。目光先落到红线，手停住后松开并收回，让出门口；用同一镜头读清转变。若这些信息无法在同一构图读清，再拆为道具证据和人物反应，按既有左右方向接上。
image_prompt：手仍挡门，钥匙已经进入可见范围，尚未让路。
result：手已收回，通道打开；下一镜从迈入动作承接，不能又从挡门开始。

悬疑，剧本：“灯与木盒不动，投影变形，研究员察觉。”
可执行描述：侧向固定机位把木盒和墙面投影同时纳入，留出完整形变范围，先让稳定投影可读，再按原文变化。研究员反应可用后续反应镜头接住，但不得遮住变化证据。
image_prompt：木盒不动，投影仍为正常形状。
result：写原文规定的形变结束状态；下镜承接已发生的异常，不再次从尚未知情演起。

儿童喜剧可用清楚的揭晓和反应停顿；悬疑可限制可见范围；人物戏可用距离与视线体现关系。选择适合本故事的一种，不把水彩、写实等外观词当作叙事设计。

每记录仍是一次生成段落，duration 服从所选模型能力。不要把一秒剪辑镜头伪装成支持生成的一秒任务。段内多镜与跨片段音桥需要后续执行验证，不承诺精确切点或已完成混音。自检只减少风险，保存后简述未实测事项。

## 必填：跨镜接续表（沿用原 result 字段）

整集重建以当前 script 为剧情依据。existing_storyboards 仅是旧记录，不能让旧事件、站位和节奏覆盖新剧本。“保留合理设计”仅指经当前剧本逐项核对后仍成立的设计。

先固定整个场景的世界布局、机位与轴线，再规划全体角色的逐镜状态。画面左/右不等于世界位置；用床尾、门边等稳定地标。镜头外的人仍在同一空间，不能因为没入画就忘记位置。动作造成的移动或外观变化必须在本镜演出；切镜本身不产生移动、反应回退或贴片转移。

每条 result 保留自然语言结束状态，末尾追加下面标记包住的 JSON（不用新增字段或修改服务端）。标记必须精确为 `<!-- huobao-continuity:v1 -->` 和 `<!-- /huobao-continuity:v1 -->`。以下仅是结构示例，人物 ID、语言与剧情按本集替换：

```json
{"version":1,"transition":"start","reason":"Opening establishes the room","space":"bed left, mirror right, door foreground; world landmarks fixed","camera":"door-side wide, camera stays on this side of the bed-mirror axis","start":[{"id":1,"position":"beside mirror","pose":"standing, paws down, facing mirror","appearance":"three bandages on cheek, no clothing","visible":true}],"end":[{"id":1,"position":"beside mirror","pose":"standing, paws down, facing mirror","appearance":"three bandages on cheek, no clothing","visible":true}]}
```

transition 仅四种：start 只能是第一镜；continuous 是同机位、同一时刻接续；cut 是换机位但时间连续；time_cut 是明确的时空跳切。reason 写切点动机，跳切还要交代省略事件，不能用跳切掩盖剧本未发生的动作。space 写固定布局，同一连续时空逐字沿用；camera 写机位与轴线。

start/end 均追踪本空间所有相关人物，包括画外的人。每人固定 id、position、pose、appearance、visible 五项。绑定角色都要有状态，入画角色必须绑定。未变化字段逐字沿用以便程序核对；同镜起止人物集合一致，出画者保留画外位置。非跳切：后一镜 start 的位置、姿态与外观必须等于前镜 end；换机位可改变 visible，不能改变世界位置。同机位连 visible 也继承。将表中约束同步写入 description、image_prompt 和 video_prompt，禁止表与文字各写一套。

分镜保存成功不等于接续验收通过。实际视频可能不服从文字；连续镜头后续须检查前镜真实结尾和下镜首帧。换机位须重新构图，不能直接复用旧机位尾帧。不要宣称已看过未读取的图片或视频。

## 剧本信息保留与镜头转译

先完整读取当前 script，不以已有分镜代替剧本。把有用的信息分成可核对的要点：事实与因果、动作过程与速度、表情和身体反应、空间与道具状态、光色材质及其变化、声音触发、信息揭晓顺序、明确的省略与禁止项。must_keep 是额外要求，不能当作唯一需要保留的清单。

默认保留所有帮助观众理解、感受或看清画面的信息。可以改措辞、换景别、合并或拆分镜头，也可采用有证据的等效表达；不要求逐句对应或复述叙事文字。删去的只能是无独立作用的重复修辞、与本段表达无关的说明。内心描写若影响动机或情绪，应转成可见行为或可听线索，不能因为“拍不到”直接删除。原文明确省略的过程不要补拍，隐藏的信息仍要保持正确状态和揭晓顺序。

在现有拆分步骤内做信息对照：原文短句 → 要保留的作用 → 目标镜头及可见/可听表达 → 保留、等效转译、合理删减或待解决。一个要点可跨镜实现，多个要点可同镜并行。所有有用要点都要找到落点；等效转译要说明为何仍能传达原意，删减要说明为何不损失信息或表现力。不能用“更简洁”“时长紧”“已有接续表”作为删除有用细节的理由。原句含糊时标明解释，不把可选导演设计说成剧本明确要求。

反查两次：先从完整剧本查 description/image_prompt/result，再从分镜查 video_prompt 和本次实际会提交的首帧/参考素材。已有资产可能承载静态外观，但未观察、未提交的图不能作为保留证据；呼吸起伏、步态、表情变化、光线渐变和声音时机仍需写进动态提示词。不能把其他业务字段存在当作模型已经收到，也不能以关键词重复证明语义完整。取景大小、遮挡和时长要让细节可读，写进宽远景里的微表情不自动算完成。

例如“被子随呼吸起伏”不能只剩“熟睡/呼吸声”；“踮脚蹑行”不能只剩“移动”；“肩膀抖动、眼睛弯起地偷笑”不能只剩“憋笑”；“逐渐变亮”不能只剩“清晨明亮”。但“清晨，窗外的光变亮”也可能仅交代新场状态，不能擅自断言必须有延时镜头；一旦制作要求明确要看到夜到晨过程，就必须提供具体可见变化。不要照抄示例情节。

时长冲突先用同镜并行、合并重复表达和调整镜头预算解决；仍放不下时报告具体冲突，不静默损失内容、不把动作挤成无法辨认的快放。接续核对之外另做信息核对，不能为防止站位错误一律锁死景别或删掉必要反应。

最终以实际读到的保存结果给出简短对照表：原文要点、分镜 ID/编号及具体表达、处理结果。列出全部删减、有用细节的削弱和未解决项；未返回的字段标为未核实。表是创作结果的证据，不是内部推理；不要写入剧本或镜头表演正文。若只获准修改 video_prompt，发现上游遗漏或矛盾先定位字段并报告，不擅改其他字段，不把未来镜头的信息提前塞入当前镜头。AI 自查不等于语义验证通过，更不等于已经验证视频呈现。

## 默认视频提示词交付规范

每条 video_prompt 是可独立提交的视频生成指令，不是剧情摘要。拆分时就完整填写，不能把专业细节留给用户再次点生成。description、image_prompt、atmosphere、摄影、sound_effect、bgm_prompt 和 result 不会自动全量传给视频模型；把本镜成立所需的信息转译到 video_prompt。已有参考图负责身份和静态外观，仍须明确动态变化、可见范围及临时道具状态。全局风格由服务端注入，局部光色材质必须与之相容，不一律改成写实或水彩。

使用下面六个短标题分段保存（中文用中文标题，其他语言可用对应英文标题、正文跟随内容语言）。各段必须有本镜具体内容，不得写“同上、按剧本、参考画面、待补充”。短转场可以简洁，不用凑字数；复杂表演应写足，不能只写“固定镜头＋动作＋无台词”。

【画面起点】 / [Frame]：写本镜开始时观众实际看见什么；谁在何处、前后层次、朝向、关键道具及遮挡。对应 image_prompt 的动作之前状态；严格限制何时揭晓。画外人物保留世界位置但不额外入画。
【动作节奏】 / [Action]：以“触发→反应→行动→停住”中本镜确有的环节写可见过程，包括视线、表情、重心、步态、接触关系与速度变化。按本镜真实时长分配事件预算，动作可合理并行，不固定三秒一段，不追加剧情；2 秒光变只描述连续光变，不硬塞完整人物表演。
【摄影】 / [Camera]：景别、机位高低/方向、轴线和构图，让关键细节实际可读。一种主要运镜，或有理由的固定机位；写运动起止与目的，不堆互相冲突的推拉摇移。镜中倒影不生成第二个实体人物。
【光色与材质】 / [Light and material]：本镜主光从哪来、方向和软硬、亮暗层次、主次色与饱和倾向；选直接影响观感的表面写具体可见表现，如柔软织物随呼吸起伏、哑光木面漫反射、纸纤维边缘。按项目风格选材质表现，不能凭空新增布景或衣物。动态光影说明变化来源，普通阴影服从光源与物体；异常必须有故事依据并明确正常基准和异常过程。不要虚构摩擦系数、弹性模量、渲染器参数或无效画质词。
【声音】 / [Sound]：说话者＋逐字台词、进入时机及完整收尾余量；继承原文，不以“介绍背景”替代文字。无语言时明确无旁白/对白，只写有依据的动作声、环境声及配乐有无，禁止含糊人声。旁白长度与动作预算冲突应报告，不能截断或极快念完。文字仅描述音轨意图，不宣称已合成或精确同步。
【结束与衔接】 / [End and continuity]：具体终态、目光/持物/位置及下镜接点，保持 reveal 顺序与方向。结束状态与 result 一致，不能重演前镜已完成的反应。time_cut 的省略发生在切口时，start 必须是省略后的本镜首帧，不能把前镜 end 当成本镜 start 再要求在镜内补演；若确为镜内可见过程，须由本镜 description 明确说明。仅补提示词时发现上游矛盾，指出字段并停止，不擅改分镜来凑齐六段。

保存前逐项反查“剧本有用信息→分镜表达→video_prompt”：动作的过程而非只有结果、表情反应、空间关系、光线变化、声音触发和揭晓顺序均需有落点。六段齐全只是信息结构检查，不证明内容正确；保存后读取指定分镜，确认确实更新，再报告删减和未解决冲突。不得把工具成功、字数或标题齐全称为专业质量验收通过。

### 实际人物状态与镜头呈现分开

position、pose、appearance 只记人物实际状态：以房间地标写位置和朝向，以身体姿态、动作阶段和实际贴片/服装/持物写状态。不要把“背对镜头”“脸未露”“首次清晰可见”“被隐藏、未揭晓”等取景或观众知情程度写进这三项；这些必须保留在 camera、description、image_prompt、video_prompt 和自然语言结束状态中，不能直接删掉揭晓设计。visible 只表示人物是否入画，局部遮挡与镜中倒影由镜头描述交代，不新增接续表字段。

例如，从背后拍一个面对镜子、脸上已有创可贴的人，切到镜中正脸：人物没有转身或换贴片。前镜 end 与后镜 start 应逐字使用同一实际状态（如“站立，面对右墙落地镜”“脸贴彩色创可贴”）；背面不露脸、镜中首次揭晓写在各镜画面字段。先建立共同的实际状态，再分别描述两种视角。新机位看见了更多细节，不等于角色发生变化；但真实的站坐、转身、表情和持物变化仍须由剧情动作支持，不能一概忽略。保存前逐对核对非跳切镜头的前 end / 后 start，纠正视角混写，不能用 time_cut 或删掉物理状态来绕过检查。
