# 视频提示词

输入是指定分镜的原字段、制作要求和绑定素材；输出只写入该分镜 video_prompt。先读数据，不能凭分镜编号猜情节。内容语言跟随全局设置，固定字段名和资产 ID 不翻译。

建议依次交代：本镜主体与场景；起始画面及光源；有因果的动作顺序与结束状态；必要的摄影、色彩、光影和材质；逐字声音；直接影响成立的限制。可按动作事件标时间，不固定三秒一段，也不为了填满时长添加无关动作。每个阶段都要说清谁变化、怎么变化、持续到何时；一个镜头只有必要的一种主要运镜。

文生视频先建立主体、空间与造型。图生视频把参考作为外观锚点，重点写动作、相机变化和终态，不重复整段静态描述。引用图片的 @名字 必须来自本镜绑定对象，不能虚构 @图片编号；无图旁白人物不应强行当作参考图。

摄影写景别、机位高低、视角、主体运动方向、机位运动的目的与终点；色彩写主次色关系、饱和与明暗层次；光照写方向、软硬、遮挡与变化来源；材质写粗糙漫反射、局部湿亮、织物拉伸、颗粒噪声等可见表现。不要仅写“电影感、高清、恐怖”，也不要塞入没有实际控制通道的弹性模量、摩擦系数或渲染器参数。

物理关系先给基准：灯不动、物不动时普通投影不会自行平移。剧情需要异常时写明从正常轮廓到何种不可能形状、边缘如何变、物体本体是否变化。怪诞感来自具体可见违常，不来自堆叠负面形容词。

声音必须写“旁白/角色名：『逐字原台词』”，说明先后及必要停顿。确保与 description 完整一致，末句有结束余量。不要把“介绍背景、讲述来历”当台词，不让无声角色发出含糊咕哝。speech_mode=none 时写清无语音；bgm_prompt/sound_effect 不会自动成为独立音轨。缺少足够时长需要回到输入调整，不能把超快语速作为通用解法。

风格前缀由服务端注入，勿重复粘贴。片名、档案编号、字幕等准确文字注明后期排版。最终自查主体与引用、台词、动作、光源、衔接与时长，然后只保存指定 video_prompt。

语音预算自查：中文旁白先以每秒约 3–4 个汉字、英语每秒约 2–3 个词作为保守规划估计，另给呼吸、动作与末句留余量，不视为实测语速。台词不够时间时调整本镜预算及相邻段落；不能为了总时长凑数压缩到念不完，也不能擅改已经确认的原台词。最终提示词写全逐字台词并标明完整结束，拒绝以“极快语速”解决。

## 保留表演过程与信息顺序

先核对起始画面、description 中的动作过程和 result。把必须执行的构图、人物位置、可见范围和声音触发写进 video_prompt，不依赖模型读取其他业务字段。用先后关系与可见变化组织动作；一镜通常保留一条主要表演线。秒数仅为节奏预算，不能声称逐帧可控。

反例：首帧已瞪眼缩头，却要求从困倦开始惊讶。
正确转换：起始为半合眼、嘴放松、脑袋未缩回；聚焦后短暂停住，眼睛睁大，身体稍后后缩；结尾仍看着镜子。若当前 image_prompt 已是最终表情，指出这个字段需要修正。仅获准更新 video_prompt 时不要擅改图片字段，也不要用含糊文字掩盖冲突。

相邻镜头已完成的发现不得重演；道具位置与状态保持连续；有故事依据的镜外对象不能擅自提前入画。角色基础图负责身份外形，故事阶段的临时贴片、持物和表情按已确认分镜描述，不能把基础图的干净状态当作全片不许变化。

不得为优化单镜添加新剧情、笑点、台词或未授权剪辑。原字段冲突无法在允许范围内解决时，返回具体冲突和建议，不把工具调用成功当作品质合格。

接续表是已确认起止状态的约束：补充数据中的 handoff.plan 给出固定布局、机位、人物位置、姿态、外观及画外状态，必须译入 video_prompt。若 handoff.issues 非空，先报告冲突；仅改提示词无法修复接续表时停止写入。不得发明角色入场、移位或外观变化来掩盖矛盾，也不得改 result 来让检查通过。

## 剧本信息保留与镜头转译

先完整读取当前 script，不以已有分镜代替剧本。把有用的信息分成可核对的要点：事实与因果、动作过程与速度、表情和身体反应、空间与道具状态、光色材质及其变化、声音触发、信息揭晓顺序、明确的省略与禁止项。must_keep 是额外要求，不能当作唯一需要保留的清单。

默认保留所有帮助观众理解、感受或看清画面的信息。可以改措辞、换景别、合并或拆分镜头，也可采用有证据的等效表达；不要求逐句对应或复述叙事文字。删去的只能是无独立作用的重复修辞、与本段表达无关的说明。内心描写若影响动机或情绪，应转成可见行为或可听线索，不能因为“拍不到”直接删除。原文明确省略的过程不要补拍，隐藏的信息仍要保持正确状态和揭晓顺序。

在现有拆分步骤内做信息对照：原文短句 → 要保留的作用 → 目标镜头及可见/可听表达 → 保留、等效转译、合理删减或待解决。一个要点可跨镜实现，多个要点可同镜并行。所有有用要点都要找到落点；等效转译要说明为何仍能传达原意，删减要说明为何不损失信息或表现力。不能用“更简洁”“时长紧”“已有接续表”作为删除有用细节的理由。原句含糊时标明解释，不把可选导演设计说成剧本明确要求。

反查两次：先从完整剧本查 description/image_prompt/result，再从分镜查 video_prompt 和本次实际会提交的首帧/参考素材。已有资产可能承载静态外观，但未观察、未提交的图不能作为保留证据；呼吸起伏、步态、表情变化、光线渐变和声音时机仍需写进动态提示词。不能把其他业务字段存在当作模型已经收到，也不能以关键词重复证明语义完整。取景大小、遮挡和时长要让细节可读，写进宽远景里的微表情不自动算完成。

例如“被子随呼吸起伏”不能只剩“熟睡/呼吸声”；“踮脚蹑行”不能只剩“移动”；“肩膀抖动、眼睛弯起地偷笑”不能只剩“憋笑”；“逐渐变亮”不能只剩“清晨明亮”。但“清晨，窗外的光变亮”也可能仅交代新场状态，不能擅自断言必须有延时镜头；一旦制作要求明确要看到夜到晨过程，就必须提供具体可见变化。不要照抄示例情节。

时长冲突先用同镜并行、合并重复表达和调整镜头预算解决；仍放不下时报告具体冲突，不静默损失内容、不把动作挤成无法辨认的快放。接续核对之外另做信息核对，不能为防止站位错误一律锁死景别或删掉必要反应。

最终以实际读到的保存结果给出简短对照表：原文要点、分镜 ID/编号及具体表达、处理结果。列出全部删减、有用细节的削弱和未解决项；未返回的字段标为未核实。表是创作结果的证据，不是内部推理；不要写入剧本或镜头表演正文。若只获准修改 video_prompt，发现上游遗漏或矛盾先定位字段并报告，不擅改其他字段，不把未来镜头的信息提前塞入当前镜头。AI 自查不等于语义验证通过，更不等于已经验证视频呈现。

## 默认视频提示词交付规范

每条 video_prompt 是可独立提交的视频生成指令，不是剧情摘要。拆分时就完整填写，不能把专业细节留给用户再次点生成。description、image_prompt、atmosphere、摄影、sound_effect、bgm_prompt 和 result 不会自动全量传给视频模型；把本镜成立所需的信息转译到 video_prompt。已有参考图负责身份和静态外观，仍须明确动态变化、可见范围及临时道具状态。全局风格由服务端注入，局部光色材质必须与之相容，不一律改成写实或水彩。

使用下面六个短标题分段保存（中文用中文标题，其他语言可用对应英文标题、正文跟随内容语言）。各段必须有本镜具体内容，不得写“同上、按剧本、参考画面、待补充”。短转场可以简洁，不用凑字数；复杂表演应写足，不能只写“固定镜头＋动作＋无台词”。

【画面起点】 / [Frame]：写本镜开始时观众实际看见什么；谁在何处、前后层次、朝向、关键道具及遮挡。对应 image_prompt 的动作之前状态；严格限制何时揭晓。画外人物保留世界位置但不额外入画。
【动作节奏】 / [Action]：以“触发→反应→行动→停住”中本镜确有的环节写可见过程，包括视线、表情、重心、步态、接触关系与速度变化。按本镜真实时长分配事件预算，动作可合理并行，不固定三秒一段，不追加剧情；2 秒光变只描述连续光变，不硬塞完整人物表演。
【摄影】 / [Camera]：景别、机位高低/方向、轴线和构图，让关键细节实际可读。一种主要运镜，或有理由的固定机位；写运动起止与目的，不堆互相冲突的推拉摇移。镜中倒影不生成第二个实体人物。
【光色与材质】 / [Light and material]：本镜主光从哪来、方向和软硬、亮暗层次、主次色与饱和倾向；选直接影响观感的表面写具体可见表现，如柔软织物随呼吸起伏、哑光木面漫反射、纸纤维边缘。按项目风格选材质表现，不能凭空新增布景或衣物。动态光影说明变化来源，普通阴影服从光源与物体；异常必须有故事依据并明确正常基准和异常过程。不要虚构摩擦系数、弹性模量、渲染器参数或无效画质词。
【声音】 / [Sound]：说话者＋逐字台词、进入时机及完整收尾余量；继承原文，不以“介绍背景”替代文字。无语言时明确无旁白/对白，只写有依据的动作声、环境声及配乐有无，禁止含糊人声。旁白长度与动作预算冲突应报告，不能截断或极快念完。文字仅描述音轨意图，不宣称已合成或精确同步。
【结束与衔接】 / [End and continuity]：具体终态、目光/持物/位置及下镜接点，保持 reveal 顺序与方向。结束状态与 result 一致，不能重演前镜已完成的反应。time_cut 的省略发生在切口时，start 必须是省略后的本镜首帧，不能把前镜 end 当成本镜 start 再要求在镜内补演；若确为镜内可见过程，须由本镜 description 明确说明。仅补提示词时发现上游矛盾，指出字段并停止，不擅改分镜来凑齐六段。

保存前逐项反查“剧本有用信息→分镜表达→video_prompt”：动作的过程而非只有结果、表情反应、空间关系、光线变化、声音触发和揭晓顺序均需有落点。六段齐全只是信息结构检查，不证明内容正确；保存后读取指定分镜，确认确实更新，再报告删减和未解决冲突。不得把工具成功、字数或标题齐全称为专业质量验收通过。
